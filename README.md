# EdTech Platform

A backend API for an educational technology platform built with NestJS and MongoDB.

## Quick Start

```bash
npm install
npm run start:dev
```

## Features

- Course & Instructor Management
- Payment Integration (Razorpay)
- CMS & Analytics
- User Management

## API Docs

Visit `http://localhost:3000/api` after starting the server.
